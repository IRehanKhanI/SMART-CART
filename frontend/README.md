# Retail Operations Command Frontend

React dashboard for the local Django and edge-AI services. Operational values are loaded from SQLite-backed APIs; the frontend contains no fallback telemetry database.

## Run Locally

**Prerequisites:** Node.js and the Django backend running at `http://127.0.0.1:8000`.

1. Install dependencies:
   `npm install`
2. Run the app:
   `npm run dev`
